# WhyTree — 박채원 (Team 11 DocDall)

- 제품: 닥달
- 날짜: 2026-10-29
- 슬라이드: whytree-park-chaewon.pptx (과제로 따로 제출)

읽는 법: 위가 why, 아래가 how입니다. 각 줄은 바로 위 단계의 how입니다.
`[씨앗]` = 처음 떠올린 닥달이 하는 일, `[새 방법]` = 지금 닥달이 하지 않는 일(슬라이드의 점선 상자).
화살표는 모두 실선입니다(각 상자의 가장 중요한 why 하나로만 이었습니다).

- 산출물을 책으로 인정받기
  - 책으로서 최소한의 분량 확보
    - 하고 싶은 이야기 중 책으로 쓸 만한 것 선택
      - 작가 내면의 글감을 끌어내기 [씨앗]
  - 이야기의 기승전결 완성
    - 막연한 아이디어의 구체화
      - 기획서 쓰기 [씨앗]
  - 전자책으로 독립출판 [새 방법]

- 표현 욕구 충족
  - 하고 싶은 이야기를 더 잘 전달하기
    - 글의 퀄리티 높이기
      - 쓴 글에 피드백 주기 [씨앗]
  - 블로그, SNS 또는 커뮤니티에 연재하기 [새 방법]

- 시간 확보의 필수성
  - 시간 계획 짜기
    - 일정관리 [씨앗]
  - 캘린더에 쓰는 시간 자동 예약 [새 방법]

- 작가의 의지 유지하기
  - 강제성 부여하기
    - 끈기가 부족한 예비 작가 돕기
      - 닦달 알림 보내기 [씨앗]
    - 약속 금액 걸기 [새 방법]
  - 진척도 시각화 [새 방법]

## 메모

- 씨앗은 다섯 개입니다: 작가 내면의 글감을 끌어내기, 기획서 쓰기, 쓴 글에 피드백 주기, 일정관리, 닦달 알림 보내기.
- "작가 내면의 글감을 끌어내기"와 "기획서 쓰기"가 "산출물을 책으로 인정받기"에서 만납니다(같은 상자).
- 꼭대기는 네 개이고, 서로 이어지지 않습니다.
