- 최종 저장 위치에서 Node 자동 시험 12개 통과.
- 별도의 임시 Edge 시험 브라우저로 로컬 UI 흐름 확인: 변경안 확인 전 일정 유지, 확인 후 전체 일정 이동, 팬에게 변경 공유, 팬 빈도 변경, 실패 중 다른 방에서 완료 처리 후 최신 상태로 복구, 두 연결 입력 칸.
- 위 UI 시험에서 페이지 JavaScript 오류 없음.

- Git 기록 12개와 제출 대상 텍스트에서 Telegram·Google·OpenAI의 대표적인 키 패턴을 검사했으며 발견 없음. 모든 종류의 비밀정보 부재를 보장하는 검사는 아님.

## 아직 하지 않은 확인

- 사용자 본인의 세 가지 수동 시나리오: 미확인.
- BotFather에서 만든 실제 편집자·팬 봇 연결과 실제 메시지 왕복: 미확인. 앱의 연결 화면에서 사용자가 토큰을 입력해야 함.
- 브라우저 권한 허용 및 운영체제에서 실제 알림 표시: 미확인. 시험 브라우저의 권한은 기본값 그대로 두었음.
- 실제 집필 지속 효과: 미검증.

자동 시험의 Telegram 호출은 대역이며, UI의 앱 대화 연습도 실제 Telegram 전달 확인이 아니다. 사용자 직접 확인 결과는 MANUAL_CHECKS.md에 따로 기록한다.

현재 로컬 예시 상태에는 에이전트의 화면 시험으로 일정 2일 이동·1장 완료·팬 주 1회 설정 및 대화 기록이 남아 있다. 실제 사용자의 책이나 원고 데이터는 입력하지 않았다.

- 사용자 보고: 앱 안내 문구는 보였으나 Windows 배너는 보이지 않았음. 실제 표시 성공으로 기록하지 않음.
- 에이전트의 별도 시험 브라우저: Windows 권한 기본값 유지 상태에서 새 스케줄 알림이 앱 알림함에 도착함.
- 읽음 처리와 새로고침 후 기록·읽음 상태 유지 확인.
- 기존 챕터 일정과 두 Telegram 대화 연결 값 유지 확인.
- 화면 JavaScript 오류 없음. 실제 Windows 배너 표시는 여전히 별도 확인 대상.
