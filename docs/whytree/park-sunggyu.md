## 실선 연결

상위 목적 아래에 그 목적을 이루는 수단을 들여썼습니다. 같은 문구가 반복되면 슬라이드의 같은 노드이며, 하위 가지는 처음 등장한 곳에만 펼쳤습니다. 슬라이드의 줄바꿈은 한 칸의 띄어쓰기로 옮겼습니다.

## 점선 연결

슬라이드의 화살표 방향 그대로, `수단 → 부가적인 목적`입니다.

```text
전문가로서의 인정 → 비즈니스 기회 확보
다른 사람에게 기여 → 내 이야기와 경험 정리
출간 기획서 작성 → 책쓰기 진행 과정 이해
내가 잘하고 있는지 알기 → 계속 쓸 동력 얻기
```

## 슬라이드 보충 문구

아래 문구는 슬라이드에 있는 설명이며, 트리의 노드로 추가하지 않았습니다.

```text
기획서 구성
책의 목적, 대상 독자,
주요 내용, 톤앤매너 등
```

```text
출판사 편집자·기획자 관점
잘하고 있는 것
수정할 것
뺄 것
추가할 것
```

```text
읽으면서 느낀 점
좋은 것과 아쉬운 것
기대하는 것
다음 장에 대한 기대
```

```text
표지와 작가 소개가 있고
정말로 책처럼 보이는 완성품

종이책 또는 전자책
```

```text
“꾸준히 중요한 것을 하고 있다”는 인식
“당신이 쓴 글을 읽고 싶다. 그게 나에게 필요하다.”
```

```text
최소 작성 기준의 구체적인 분량·시간은 아직 미정
```
